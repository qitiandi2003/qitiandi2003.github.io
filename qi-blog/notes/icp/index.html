ICP 的误差很小，点云就对齐了吗？

从一面平墙推导点到面残差，理解配准初值、几何退化和内点覆盖率之间的关系。

Qi2026-11-26约 3 分钟

配准先要写清变换方向

假设绕着一个瓶子采集了两帧点云，第一帧作为目标，第二帧作为源。希望估计的 T 把第二帧的点变换到第一帧坐标系。绘图时保留目标点云的位置，只对源点云施加 T，就能直观看到误差方向。

ICP 交替完成两件事。先用当前位姿寻找目标中的近邻，再利用选中的点对更新刚体变换。初值相差过大时，瓶颈可能配到瓶身，迭代也会沿着这批错误对应继续下去。Open3D 的全局配准教程先求粗对齐，再用 ICP 微调，正是为了解决这个起点问题。

把点沿墙平移十厘米

设目标是一面 z = 0 的理想平墙，法向量为 (0, 0, 1)。源点经变换后，与匹配点的位移为 (0.10, 0, 0) 米。点到点距离是 0.10 米，点到面残差是位移与法向量的点积，结果为 0。现在把偏差改成 (0, 0, 0.10) 米，点到面残差随即变为 0.10 米。

同样大小的移动，在优化器眼里提供的约束可以完全不同。若画面里只有这一面墙，沿墙滑动和绕墙面法线旋转都难以从点到面残差中恢复。把墙角、桌沿或其他方向的表面纳入重叠区域，再观察配准结果，更容易区分这些运动。

同时记录内点误差与覆盖范围

Open3D 会给出 fitness 和 inlier_rmse。前者反映通过距离门限的对应覆盖情况，后者汇总这些内点之间的距离。若只有很小一块平面重叠，内点误差也可能很小。

可以用 Open3D 教程自带的两帧点云做对照。固定源与目标、距离门限和采样方式，只改变初始位姿。每次保留双色叠加图、对应数量和两个指标，检查边角能否同时重合。如果只有一面墙贴紧，就回头检查初值和场景几何。

在 Coding_Skills 的点云复核笔记里，门框是一个具体的检查对象。把配准前后的同一小段门框单独裁出，关闭颜色，从正面和侧面看两层点是否仍然分离。这能把全局误差还原为问题所在的那一小块几何。
