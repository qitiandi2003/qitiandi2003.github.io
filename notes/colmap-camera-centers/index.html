COLMAP 位姿里的负号

轨迹里有了旋转和平移，画出来却穿过墙面。把世界原点和相机中心各代入一次，就能检验位姿方向。

Qi2026-11-26约 3 分钟

把相机中心代回方程

COLMAP 导出的图像位姿将世界坐标变到相机坐标，写成 Xc = R Xw + t。相机中心 C 在自己的坐标系里是零，所以 C = −Rᵀt。举个例子，若旋转是单位矩阵，t = (−2, 0, 0)，相机中心就在世界坐标 (2, 0, 0)。

读文本模型时还要核对四元数顺序。COLMAP 把实部写在最前面，依次是 qw、qx、qy、qz。图像标识符也可能跳号。用图像名称和标识符做关联，再按拍摄时间画轨迹，能够避开把注册顺序误当时间顺序的问题。

把 COLMAP 位姿交给采用 OpenGL 相机约定的预览器时，可先求出相机中心，再处理朝向。平移列直接用 −Rᵀt，旋转部分在 Rᵀ 的基础上翻转相机局部的 y、z 轴。若直接给平移列的 y、z 分量也取负，改变的就成了世界里的相机位置。用同一张照片验算，再检查它所属相机的焦距和主点，能把朝向错误与错用内参分开。

为什么转角处断了一段

把成功注册的图像按时间排开。走廊两头各有一簇相机，中间刚好是急转弯，可以打开转角前后的图像，看共同可见的静态物体还有多少。相邻帧几乎没有重叠时，提高特征数量也补不回离开画面的物体。

有重叠却仍然断开，就检查通过几何验证的匹配及其空间分布。若匹配几乎全落在一块重复纹理的墙砖上，换一对能同时看见墙角、地面和门框的图像，再判断两段是否有可靠连接。

误差小，还要看图像覆盖

先问目标区域被哪些相机看见，再读三维点的重投影误差和观测轨迹。假设一百张照片只注册了入口处的二十张，入口处的平均误差再小，也不足以说明走廊尽头重建得怎样。把未注册图像的时间段和空间位置记下来，下一次采集就有了明确的补拍位置。
