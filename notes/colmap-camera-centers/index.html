序言

在书桌上放一台相机，再把相机往右平移。镜头向右走，桌上静止物体在相机坐标中却向左移。位姿数据里的负号正是从这种观察角度来的，先弄清“在谁的坐标系里描述谁”，后面的矩阵运算才有意义。

一张图里有两个原点

世界坐标系固定在书桌上，相机坐标系则随镜头移动。同一个笔尖可以在桌边量出一组坐标，也可以从镜头中心量出另一组。COLMAP 的图像位姿把世界中的点变到相机坐标，写成 Xc = R Xw + t。Xw、Xc 分别是同一点在两个坐标系中的坐标，R 把世界分量旋转到相机轴方向，t 是随后加上的平移。

把世界原点 Xw = 0 代进去，便得到 Xc = t。也就是说，t 描述的是世界原点在相机里看起来在哪里。画轨迹需要的是另一件事，即镜头中心在世界里在哪里。这两个问题互为逆向，镜头发生旋转时，两组数值连分量方向也会不同。

矩阵乘法在这里做了哪两步

可以把 R 的每一行看成相机一条轴在世界坐标中的方向。世界向量与第一行做内积，得到它沿相机 x 轴的分量，其余两行同理。变换坐标时，光写 R 只能重新表达方向，原点还没有搬到镜头上，因此还要 t。对方向向量本身，例如视线朝向，则不加平移。

两个检验比记公式更容易坚持。第一，镜头中心经过世界到相机的完整变换，应该回到零。第二，世界中的一根方向箭头在两个坐标系中长度应相同，因为 R 是旋转。若变换后箭头长度变了，先核查旋转的构造、单位四元数或外部引入的缩放。

从镜头中心的定义推回去

把镜头中心在世界中的位置记为 C。镜头中心在它自己的坐标系里一定是 (0,0,0)，因此 0 = R C + t。移项后 R C = −t。对合法的旋转矩阵，转置 Rᵀ 就是逆旋转。左乘它，得到 C = −Rᵀt。取回任意点的世界坐标也遵循同样顺序，先从 Xc 中减 t，再用 Rᵀ 将方向转回去。

假设相机的 x、y、z 轴分别与世界坐标系的同名轴同向，R 就是单位矩阵。若 t = (−2,0,0)，相机中心就是 (2,0,0)。这个例子只靠改符号就能算对，所以容易掩盖实现里遗漏逆旋转的问题。

加一个九十度旋转试算

取一个简单旋转，让它把任意向量 (x,y,z) 变成 (−y,x,z)。设 t = (1,−2,0)，则 −t = (−1,2,0)。逆旋转把 (a,b,c) 变成 (b,−a,c)，所以 C = (2,1,0)。将它代回正向变换，先旋转得 (−1,2,0)，再加 t 恰好为零。直接把 −t 作为轨迹点会得到 (−1,2,0)，这次显然不同。

读位姿时，四元数也是一种表达旋转的方式。COLMAP 的顺序是实部 qw 在前，然后是 qx、qy、qz。别的库可能按 x、y、z、w 接收。先用单位旋转，再用上面的九十度例子测试，既可以检查分量顺序，也能看到旋转方向是否反了。

把地图上的点送回原图

COLMAP 的相机坐标通常取 x 向右、y 向下、z 向前。再选一点 Xw，让它离开相机中心。用该帧的 R 与 t 求出 Xc，若 z 为正，点才在镜头前方。对无畸变针孔相机，像素横坐标 u = fx·x/z + cx，其中 fx 是横向像素焦距，cx 是主点横坐标；纵坐标用 fy、cy 同样计算。原图有畸变时须使用相应的相机模型。

实际核对可以从桌角上一个看得清的点开始，挑几张相隔较远的图看看它是否都落在同一个物理角点上。导出轨迹时按图像名称关联拍摄时间，别假定图像标识符连续或等于时间顺序。最后给图注明世界坐标系和尺度来源；单目重建里两个相机中心的距离首先是模型单位，要换成米还需要独立尺度。

一个很实用的中间量是相机的朝前方向。取相机局部向量 (0,0,1)，只用逆旋转 Rᵀ 把它变到世界系，再从中心 C 沿这个方向画一小段。中心都落在走廊内而镜头箭头朝墙外，通常提示需要优先核对朝向或相机轴约定。

用完整数字把一个路标送回图像

沿用上面的九十度旋转与 t = (1,−2,0)，选世界点 Xw = (2,0,4)。先旋转得到 (0,2,4)，再平移得到 Xc = (1,0,4)。它在镜头右侧，光轴深度为 4。给定 fx = fy = 600 像素，主点 (320,240)，假定没有畸变，该点应出现在 (470,240)。从 320 到 470 的 150 像素，正好是 600 × 1/4。

可再做一次反向检查。把像素横向偏差 150 除以焦距 600，得到相机坐标中 x/z = 0.25；若已知深度为 4，就能还原 x = 1。若只有像素而没有深度，得到的是一条射线，无法凭这一个像素唯一地倒推出 Xw。这样就把变换方向错误与缺少深度这两类问题分开了。
