给已有的三维重建补几张照片

区分新照片定位、三角化和联合优化，从两段有重叠的拍摄理解怎样扩展模型并复查旧视角。

序言

拍完一个房间才发现书柜侧面的文字模糊了。最自然的反应是拿起相机专门去拍那一面；但如果新照片张张只有文字特写，计算机未必知道它们属于旧房间的哪一侧。补拍首先要接上旧地图的坐标。

新照片如何找到自己在旧房间里的位置

已有的稀疏模型通常包含旧相机位姿、三维路标，以及哪些图像特征看见了哪些路标。当补拍照片中也出现旧柜角、墙缝或海报边缘时，可把新图像上的像素连到已知三维路标，据此估计新相机位姿。这一步称为注册。它回答的是新照片从哪里拍摄，还没有为书柜侧面的新文字建立三维点。

补拍时可以先站在接近旧机位的位置拍一张，再逐步向侧面移动，让相邻照片之间持续保留共同可见结构。若从旧正面直接跳到背面，中间完全不可见，照片数量再多也不一定能建立两套坐标之间的关系。

从注册到三角化，再到联合调整

可以把数据写成一个对应表。旧图 A 中的像素 a 和旧图 B 中的像素 b 已经对应地图点 P。补拍图 C 中的像素 c 若与 a 匹配，就得到 C 里一个像素对应已知 P 的关系。与其他已知三维点一起，这些对应可用来估计相机 C 的位姿。此时 P 原本就存在，加入观测 c 并不等于增加一个新路标。

若 C 和另一张已定位的新图 D 都看见了一道旧图没拍到的书脊棱线，二者对应像素才有机会通过三角化生成新点 Q。之后可以调整多个相机位姿和路标，使同一个点投回各幅照片的误差共同下降。这个优化称为光束平差。只有新图注册成功、以及继续生成新几何，所需输入和能得到的结果都不同。

为什么只在原地转动还不够

当书柜侧面的同一个角点出现在两个已注册机位中，从两个相机中心沿观察方向各引一条射线，便可估计它的位置，这叫三角化。两条射线夹角很小时，一点像素误差就能让交会深度相差很远。若只在原地转动，相机中心完全没变，射线不提供用于测深的基线。

做一组简化计算。两张校正照片的相机中心相距 0.10 米，焦距 600 像素，某点视差为 20 像素，则估计深度约是 3 米。如果两机位只差 0.01 米，同一目标的视差约为 2 像素。后一种情况下，一像素误差对深度的影响明显更大。实际补拍还得保证两侧都看得见目标，跨度增加到失去重叠同样无助于三角化。

让原有画面也参加复核

只把新照片定位到现有模型，和继续重建、增加路标并联合调整相机，是不同的操作。联合优化时，新观测可能让旧相机和旧路标一起移动。对渲染流程而言，新位姿集合会改变训练输入。比较两版前，先明确使用的是哪一份相机参数以及两版如何对齐到同一参考系。

留出几张没有参加优化的照片做检查，分别覆盖新拍的侧面、接缝处和原本清晰的正面。裁出相同内容，比较柜边位置、文字重影和遮挡变化。若只看新侧面，可能看不到正面已经发生的退化；若只读一个全局平均值，侧面的一小块改善也会被大面积白墙淹没。没有独立深度时，可以报告经这些视角验证的外观变化，几何尺寸精度还需要额外测量。

留哪些图片才能检验真的变好了

连续视频相邻帧常常几乎一样。如果把一帧用于训练、紧挨着的下一帧拿来当测试，新视角的难度可能被低估。可以预先留出一段连续侧移照片，再另选旧路线上的几个固定位置，明确哪些图只用于检查。两次对比使用同一批参考图、同样尺寸、同一裁剪区域，才便于解释哪项变化真的改善了边缘。

还有一种看似严重、实则属于参考系的变化。假设联合调整后整个模型等比例旋转、平移，且相机与路标一起变换，内部像素投影仍可相同。比较坐标前先用共同相机或稳定路标把两版对齐，再看检查点是否局部变形。若要继续训练高斯或对已有网格做评估，也要确认模型、相机和深度采用同一版参考系。
