用 BERT 判断一条评论的情感

跟随一条有转折的酒店评论，从分词、截断到两个类别分数，检查模型真正看到了什么。

序言

“房间很安静，但半夜停电了，体验很差。”这条评论既有正面词，也有负面词。简单数词频很难判断作者最后在说什么。BERT 可以让一句话中各位置的表示随上下文而变化，再用人工标注的例子学习情感类别。

文字进入模型之前

分词器先把字符串变成模型词表里的基本单位，通常叫 token。它可以是一个中文字、一个完整词或词的一部分，取决于所用分词器。许多 BERT 分类输入会在句首放 [CLS]，在句尾放 [SEP]。这些特殊符号、分词结果和填充符各自都有编号。位置表示则帮助模型区分“其实不错，起初担心”和“起初不错，其实担心”。

一个批次中，短评论可能要补齐到相同长度。注意力掩码告诉模型哪些位置是真实输入，哪些是为凑齐形状而填的。若设最大长度为 128，它限制的是包含特殊符号的 token 总数，而非原文恰好 128 个汉字。对长评论，若策略只保留开头，结尾的“体验很差”可能在送入模型之前就消失了；再好的分类器也不能凭空读回丢失的文字。

实际诊断时，最好看模型收到的三样东西：解码出来的有效 token、它们的位置和掩码。给“房间明亮但很吵”和“房间明亮也安静”做一个玩具示范，暂按一字一 token，只允许四个正文 token，两条都会只留下“房间明亮”。真实分词器还需为句首句尾符预留空间。把限制从四个正文位置调到七个，才有机会观察结尾变化是否影响分类。

分类器怎样得到两个分数

BERT 的每层都会让位置之间交换信息，这种运算叫自注意力。在分类场景中，“差”附近若出现“不算”，对应表示有机会包含否定的影响。分类网络通常取句首特殊位置最终得到的表示或由它变换的池化表示，再经过一个小的分类头，得到每个类别的原始分数。这些分数常叫 logits，可以为正，也可以为负。

假设标签顺序是“负面、正面”，某条评论的两个分数是 0 和 2。softmax 会先对各分数取指数，再除以总和，正面分数便转换成约 7.39 ÷ (1 + 7.39) = 0.88。若标签表顺序写反，输出数值完全相同，显示给读者的意思却恰好颠倒。0.88 表示这个分类器对所设类别的相对偏好，遇到分布不同的评论时，不能未经校准就把它解释为可靠的现实正确率。

预训练学会读句子，微调学习标签

预训练阶段，原始 BERT 会在大量文本上做遮盖词预测等任务，借此学习上下文表示。微调时再准备带“正面”“负面”标签的训练评论，让模型为每条评论输出分类分数，按正确标签计算交叉熵并更新参数。分类头和编码器都可以一起微调。将“中性”“好坏混合”硬归入二类之前，先检查标注规则到底要求表达整体满意度，还是只标某一个方面。

要检查“末尾转折丢失”，可以写两条开头完全一样的评论，使唯一差别出现在很靠后的“仍愿意再来”和“不会再来”。先打印两者在实际长度限制下的 token 和掩码。若它们截断后完全相同，在相同参数、评估模式和确定性计算下，两次分类分数应相同。再把转折移到首段检查预测。如果输入已经不同、预测依旧相反或一样，就去看模型对否定与语境的学习，而不能把每次错判都归因于截断。

评估时把短评、超长评论和带转折的评论分开看，还可换一套酒店或时间段留作测试。训练和测试里若出现几乎一样的模板，模型只需认出模板就能拿到高分。读几条具体误判，同时标明正确标签、预测标签和实际保留的文本末尾，往往能看出下一步应调整文本处理、补充样本还是修订标签定义。

从分类分数看一次参数更新

对二分类交叉熵来说，一条样本的损失就是正确类别概率的负对数。沿用前文正面约 0.88 的输出：若真标签为正面，这一项为 −ln(0.88) ≈ 0.13；若标注为负面，正确类别概率约 0.12，损失约 2.12。高把握的错误比犹豫的正确判断提供更强的纠正信号。实际训练可把原始分数交给能稳定计算对数 softmax 的损失函数，避免对同一组值归一化两遍。

同一分类分数还可能对应不同业务决定。假设把模型判为负面的评论列入人工回访，阈值从 0.5 提到 0.8，会放走一部分低把握样本，也会减少不必要的回访。保留一个在训练中从未见过的小验证集，分别统计改动前后的误报和漏报，并查看“环境满意、服务很差”这种混合句被如何标注。这样才能分清模型判断、标签定义和后续处置各自承担的工作。
